# 识别模型离线 A/B（2026-09-30）

仅评估识别层；生产仍使用 R50 INT8。阈值是探索性结果，不是部署建议。

本轮判断：AuraFace 在这位本地用户的可检测自拍上值得继续评估，但保留现行 ratio 0.75 时，LFW 多账户测试的拒识明显多于 R50；SFace 的 LFW 距离门表现较好，本人侧脸跨姿态距离及 ratio 通过率较差。当前证据不足以把任一候选直接替换上线。下一步优先给 AuraFace 做独立 INT8 量化与多位用户/跨会话摄像头采样，再用更大的独立异人集标定距离门与 ratio 的组合；SFace 保留作轻量备选。

数据边界：本轮没有使用 `my_faces/occlusion_test/`。该目录是遮挡测试，允许检测不到人脸，不计入正常人脸的检测覆盖或识别结论。本地样本只取 `tools/threshold_calibration/data/lfw_subset/me/` 下带 `front_` / `left_` / `right_` 前缀的 26 张自拍；这里报告的检测失败来自这些自拍，不是遮挡测试。

环境：Windows-10-10.0.26200-SP0；Python 3.9.13；ORT 1.19.2；CPU EP，intra-op 8 / inter-op 1。

同一份 SCRFD INT8（512×512）检测和生产几何对齐 chip，三个识别器共享。候选保持发布方 FP32；R50 是现有 INT8，耗时不能解释为同精度量化比较。

## 检测覆盖与迁移影响

原自拍每个分辨率均尝试 26 图，原分辨率仅 14 图、半分辨率仅 13 图可检测/对齐。这些失败在三模型中相同，不归因于某个识别器；上面的 TAR 只统计成功取得 chip 的 probe。本轮原分辨率右侧脸只有 1 张独立 probe，侧脸小样本不能支持总体通过率结论。

- AuraFace 输出 512 维，归一化 RGB，与当前识别接口接近；仍需重新录入、标定阈值/ratio/学习门，并评估量化和慢机性能。
- SFace 输出 128 维，输入为原始 RGB 0..255；当前 512 维存储/协议校验及匹配/学习门需联查。其 norm 全样本最大 16.02，当前学习 norm 门限 19.1 不能沿用。
- SFace 的归一化 embedding 与 OpenCV 官方 FaceRecognizerSF 接口核对，最大绝对差 0.00000017。


## 来源、复现与边界

- 候选版本、下载 URL、SHA-256、许可来源见 `tools/threshold_calibration/recognizer_candidates.json`。
- 个体记录、失败项、嵌入、chip 与 JSON 结果仅存在 gitignored `data/recognizer_ab/`。公开报告只含汇总。
- 正脸与侧脸自拍是本地小样本；LFW 是网络照片，未执行 CFP-FP/CPLFW 标准协议。
- 没有 PAD、相机曝光、连续计帧、学习状态和锁屏端到端测量；分辨率缩小不等于真实暗光相机。
- 距离和未经归一化的 norm 都是模型特定量，不能直接沿用 R50 匹配/学习阈值。
- 本人 ratio 的次佳距离取所有采样 LFW chip 的最近值；它是探索性拒识门，不代表实际已注册账户数量。
- 线程设置与生产上限一致，但 Python ORT 版本、独立 session 池与 C++ 全局池不同；这些是本机离线耗时，不是慢机或生产 E2E。

## C++ 识别器交叉验证

显式构建 `EmbeddingTest` 成功，使用同一批 14 张原分辨率自拍 chip，通过现行 C++ `OnnxRecognizer`（ORT DLL 1.23.2）分别运行 R50 和 AuraFace：两者均 14/14 成功、输出 512 维；同角度距离 p50/p90 分别为 **0.692332/0.868638** 和 **0.622955/0.738961**，与 Python 结果吻合到六位小数。原生 embed 中位耗时分别为 **10.51 ms** 和 **32.16 ms**，仅作小样本交叉核对。

执行时 ORT 输出了大量 ONNX schema 重复注册诊断，但进程退出码为 0，两模型加载和推理完成。本轮未处理这个运行库诊断；Python 对比结果没有依赖其静默成功。SFace 的输入与维度需要适配，未送入当前 C++ 识别器。未运行 standalone、GUI 或锁屏，因为生产代码和模型未切换。

```powershell
cmake --build build --config Release --target EmbeddingTest --parallel 8
./build/tools/embedding_test/Release/EmbeddingTest.exe tools/threshold_calibration/data/recognizer_ab/native_chips_112 assets/models/w600k_r50.onnx tools/threshold_calibration/data/recognizer_ab/models/auraface_v1.onnx
```
