# 渐进式学习实施方案 v2(定稿)

> 本方案与实现/标定记录来自 R50 阶段。当前 SFace 试用构建强制关闭渐进学习；以下阈值与标定结果不适用于 SFace，重新启用前须完成独立验证。见 [`sface-trial.md`](sface-trial.md)。

> 2026-09-04 定稿。目标:用认证结果反哺模板,人脸解锁越用越准;**阈值 0.80 与 [0.70,1.00] 带永不改**。两条通道:**自动通道**(§3,成功路径 EMA 治日常漂移)+ **密码通道**(§5,失败+密码治深尾)。修订史见文末;文献锚点:MagFace/QMagFace(范数=质量信号)、PFE(不确定性聚合)、Uludag DEND(聚类遴选)、Biggio/Lovisotto(投毒攻击协议)。

## 1. 红线

1. **更新门 ≪ 认证门**:自动通道距离 ≤ min(目标槽纪元 p20, 上限),上限默认 **0.65**,控制台滑块可调 **[0.60,0.68]**(2026-09-05 起,config 硬钳 [0.35,0.68];68=0.01 网格上低于跨角度最小距离 0.681 的最大值);距离门对**姿态选定的目标槽**计算(9-05 起,见 §3),纪元窗口**按槽独立**(9-05 起,正脸活跃不得收紧转头槽的门;槽窗 <5 轮回退账号池化窗,再不足回退上限),并过 yaw/pitch 锥门复检(|探针−目标槽标称角|<25°,V5 字段);**0.70+ 永久禁止**(反超跨角度样本最小值 0.681 后只剩概率性保护)。落点明确性门(最近比次近近 ≥0.10)自 9-05 起仅存 V4 回退路径。密码通道 ≤0.95,身份由密码标签承担。
2. **活体失败帧绝不入学习流**(两通道同;PAD 全过是前置)。
3. **跨角度绝不平均**,每角度独立模板;保护=姿态选槽(目标槽由探针 yaw 定,非嵌入距离)+对目标槽的距离门+锥门复检(V4 回退路径为距离最近+明确性门)。**模板对间距只观测不拒绝**:每笔更新记录最小对间距,<0.68 记一条 WARN——同账户收敛是覆盖退化(接受域变小,fail-safe 方向)非安全洞,拒绝式哨兵的误报会焊死整个学习通道(9-04 装机实证:0.60 存量对拦截全部提交)。
4. **范数门=垃圾帧地板**:全局 19.1(V4 存量档),按用户录入 p5 待 V5;范数必须在 L2 归一化前取(`onnx_models.cpp` ComputeEmbedding 内归一化,过管道后现算恒为 1)。
5. **可回滚**:每日首笔更新前 `users.dat`→`.bak` + 内存最近 3 代;双开关全关=模板字节级只读。
6. **写盘不在认证路径**:更新成功才起 ~30s 静默防抖 flush,服务停止若脏强写;不设周期定时器、不设"攒满 N 次"参数。
7. **双独立开关** `ema_learning` / `failure_learning`(默认均 true;落地时 `progressive_learning` 改名,现网未写该键零迁移)。

## 2. 标定结论(三机 580 成功轮,2026-09-03/04;工具 `tools/learning_calibration/`,日志保留 14 天)

| 机 | p20 | p50 | p90 | 备注 |
|---|---|---|---|---|
| 1360P | 0.545 | 0.599 | 0.717 | |
| dev | 0.598 | 0.658 | 0.765 | |
| YY | 0.722 | 0.771 | 0.844 | 纯环境漂移(勿再叫暗光机),头号受益者 |

- 三机 p90 全 >0.70 → 收益明确,开工判据满足。
- **范数-距离相关性只分机算**(YY −0.54 强,好环境机 ≈0);池化值是 Simpson 假象,禁止引用。
- 刚录入即解锁基线 0.47,日常稳态漂移 +0.17——即学习要回收的量;验收线由此定(§8)。
- 录入 5 帧等权平均已拿 ~90% 收益(k 曲线饱和,勿加帧);平均后不重新归一化=**非 bug 勿修**(单方面改=全线收紧阈值 2–4%)。
- 跨角度模板对最小距离 0.681(26 张标定);异人证据:全量 LFW 99.86% 对 ≥1.25,审计真异人最差 0.963。
- 慢尾 KPI:绑定尝试数×时长 r=+0.836(YY p90=12 次=3–7s),学习收距离分布直接消慢尾。

## 3. 自动通道:成功路径 EMA

**已按定稿实现(2026-09-04)**:V5 标称角(读写/CP/测试)、协议 v5 姿态透传、锥门+明确性门、`learning_distance_gate` 0.65 钳 [0.35,0.68](2026-09-05 上限 0.65→0.68 并加控制台滑块 [0.60,0.68],供漂移大户实验)、双开关改名(`ema_learning`/`failure_learning`,旧键读兼容)、哨兵拆拒绝→观测 WARN、录入端标称角+对间距软提示、poison_sim P0/P1/P2 全绿。存量 V4 文件升级读(角=无效哨兵→锥门开启,由距离门+明确性门+PAD 兜底),重录后才获锥保护。中间态(0.60 无 yaw,提交 `6094b24`/`c3ad909`)已被本版取代。
**2026-09-05 二次修订(装机观测驱动)**:更新目标改为**姿态选槽**——1360P 重录后三槽重叠(对间距 0.654–0.659<0.68),距离最近槽与探针实际姿态槽可不一致:过渡帧(±15–25°)被正面槽吸收致槽间塌缩,而锥门内姿态正确的探针被整笔丢弃。现 V5 路径:目标=|探针 yaw−各槽 nominalYaw| 最小者(平手取嵌入距离小者;混合账户只从 V5 脸中选,V4 脸冻结),距离门对目标槽按取时模板现算(dTarget ≥ 命中距离,单调更严),锥门复检(挡 |yaw|>55° 等极端);明确性门从 V5 路径移除(yaw 已接管槽归属),V4 回退路径(无标称角/探针姿态无效)保持距离最近+明确性门原样。选槽边界从命中槽 ±25° 锥移到标称角中点(±15°)。`TemplateLearnerTest` 9 用例覆盖。

### 门控(全部满足才更新)

| 门 | 规则 |
|---|---|
| 入场 | 认证成功(隐含活体全过+3 帧共识+同 SID) |

| 角度锥 | \|探针 yaw − 目标槽 nominalYaw\| < 25°,pitch 同理(V5 字段;V4 无标称角跳过) |

| 范数 | ≥19.1 |
| 节奏 | 距该槽上次更新 ≥60s(9-05 起**按槽独立**,正脸解锁不占转头槽的节奏预算);α'=0.10/(1+n)(n=**该槽**当日已更新次数,9-05 起按槽计数) |

EMA:取终态 3 绑定帧中距离最小帧,`t_new = normalize(α'·x + (1−α')·t_old)`;位移上界 1−(1−α)^k(α=0.1 时 7 次注入才移动 52%,且每次都要过活体+全部门)。时序:AUTH_SUCCESS ACK 时入队,学习线程延迟 2s 再处理(避开解锁后系统繁忙窗口)。

## 5. 密码通道:失败+60s 内密码→学习(co-update)

对照 Apple Face ID:失败后立即输密码且近失时更新存储的人脸——同样有距离门,密码标签只是为够不着自动门的难例开第二条**有门**的路。本通道负责深尾 0.65–0.95。

**四项定案**:直写 EMA(不走候选池);硬上限 0.95(`learning_labeled_cap` 钳 [0.70,0.95];YY 失败带 0.815–0.927 全覆盖,审计真异人最差 0.963 之下留边);单账户判定=**有已录入人脸的账户数==1**(多账户机本通道自动关闭);开关 `failure_learning`。

### 链路

```
[worker] 抓帧→PAD→嵌入→身份未中(Retry)
 └ 捕获"PAD≥阈值 ∧ 身份未中"的最佳帧 ──→ AuthFailed(v5,可选探针块)
[父进程] 暂存候选(单槽/只留最后轮/取距离最小者)
 ← WTS_SESSION_LOGON → 用户名→SID(LookupAccountName)→ 匹配 users.dat
 候选年龄≤60s ∧ 有脸账户==1 ∧ 开关开 → 入队(passwordLabeled=true)
 → 复用自动通道全部机器,仅距离门换 ≤0.95(选槽与门控同自动通道)
```

关键落点:
- **候选必须在 worker 侧捕获**:只有管线同时知道"该帧 PAD 过"和"身份未中";Retry 路径的 PAD 分现算完即弃(`auth_pipeline.cpp`),须加阈值判断再决定收不收。
- **协议 v5**:AuthFailed 追加可选探针块(嵌入+norm+距离+PAD 分+yaw/pitch 估计),严格解码。
- 窗口 60s,以最后一轮失败刷新;standalone 分支不启用(已登录会话无意义)。

### 威胁模型

| 威胁 | 挡住它的机制 |
|---|---|
| 陌生人知道密码,故意失败+输密码灌脸 | 脸距 1.2+,0.95 硬上限直接丢弃 |
| 反复"失败+密码"刷更新 | ≤0.95 受 60s 间隔+α 日衰减+位移上界(P3 复核) |
| 错槽/多角度干扰 | 姿态选槽(yaw 定目标)+对目标槽距离门+锥门复检(V4 路径:明确性门)+ 对间距观测日志;槽重叠终局=延后的新槽 |
| 空场景/超时轮误入 | 候选仅来自"有脸 ∧ PAD 过 ∧ 身份未中"帧 |

## 8. 实施与生效判定

**顺序**:§3 已实施完毕;§5 密码通道另行开工。两个易漏点:standalone 分支同样挂学习钩子;协议新字段同步加测试用例。

**生效判定(三层+密码层)**:
1. **机制**:每笔更新一条 `Template updated: ...` 日志,30s 后落盘且 `.bak` 存在;测试绿;字节级对比 users.dat 仅命中模板变化。
2. **效果**(2–4 周):非当日录入稳态 p50 ≤0.58、p90 ≤0.70;环境分裂用户用相对线(同环境稳态 p50 较上纪元降 ≥0.05 或慢尾轮占比减半);边缘失败(closest∈[0.70,0.80])周计数下降;绑定尝试数 p90 回落至 ~3。
3. **安全与槽位卫生**(每笔更新记录,只记不拒):模板对最小间距常态 ≥0.68,<0.68 记 WARN(存量近对**不阻塞学习**);异人距离带基本不变;开关全关时模板只读。
4. **密码通道**:故意失败+输密码后出现 `Template updated (password-labeled)`;YY 失败率按周下降;P3 借密码录脸零位移。
