# 本地开发约定

这页只记录编码约定。构建、依赖、standalone 启动和验证命令统一见 [`BUILD.md`](../BUILD.md)；任务路由见 [`DEVELOPMENT.md`](../../DEVELOPMENT.md)。

## 编码约定

- C++ 使用 C++20；MSVC 按 UTF-8 编译，启用 `/W4`，不把警告视作错误。
- Win32 线程同步使用项目现有的临界区、事件和原子标志；改动前检查对象所属线程及生命周期。
- 函数以返回值报告成败，详细错误写项目日志；不要用异常作为控制流。
- 密码不得写入日志；所有退出路径都要清除敏感缓冲区。
- 使用 `FACELOGIN_*` 日志宏；Go 代码遵循 `gofmt`。

协议、持久化格式及模块边界分别见 [`contracts/`](../contracts/) 和 [`modules/`](../modules/)。
