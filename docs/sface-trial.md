# SFace 试用切换（2026-10-01）

本次按用户要求切换识别模型并强制重新录入；旧 R50 数据不兼容，不进行特征转换。当前仍是试用验收，不能把离线通过率解释成生产安全保证。

## 运行模型与边界

- 识别：OpenCV Zoo `face_recognition_sface_2021dec.onnx`，固定上游版本 `47534e27c9851bb1128ccc0102f1145e27f23f98`。2026-10-04 清理重复的 174 个 initializer graph inputs 后，运行文件为 38688787 字节，SHA-256 `ae6a6ac44d2bdc87924e75fb23d8212430dd24f037f5e035c21deff99afc8b61`；权重/节点保持原样，上游原始哈希保存在 provenance。本次规范化保持已有 V6/SFC1 和录入数据，无需重新录入；数值与旧库匹配对照见 [性能记录](sface-performance.md)。
- 输入：RGB float32 NCHW 1×3×112×112，原始像素 0..255；图中已包含归一化。输出 1×128，C++ 验证维度/有限值并 L2 归一化。
- SCRFD 检测/5 点对齐、双 MiniFAS PAD、计帧一致性、曝光控制保持原流程。模型在服务、worker、注册端验证同一 SHA-256。
- 匹配默认/上限 1.00，下限 0.70，最佳/次佳账户 ratio 仍为 0.75。这是保守试用范围，比离线探索阈值 1.0693 更严格；未完成生产 FAR 标定。
- config 新增 `recognizer_model=opencv-sface-2021dec`。无此标识的旧配置重置识别阈值，保留相机/PAD等设置；旧注册表阈值不沿用。
- 渐进式学习强制关闭，包括旧配置手工写入的 true；设置页禁用开关。19.1 范数门和学习距离门是未启用的 R50 历史参数，不作为 SFace 标定。

## 强制重新录入

`users.dat` 只写入 V6，header 为 magic/version/accountCount/recognizerTag（各 uint32），模型标识 SFC1。每条嵌入只能是 128 维；worker 协议升级至 v8，不接受旧 R50 探针。

V4/V5 不读取任何人脸或密码，活动账户为空，日志和注册程序提示重新录入。旧文件在首次完成新录入保存前保持原样；新录入写入 V6 后，每个其他账户也需要重新录入。Credential Provider 不显示旧库对应的人脸登录磁贴。其他版本、错误模型标识、损坏 V6 继续 fail closed。

每个角度单独存储，同角度采样平均后 L2 归一化，不跨角度平均。建议一次重新录入正面、左转和右转三个角度。

## 试用与待验收

从本次新生成的安装包安装后，打开注册控制台重新录入所有账户，再测试日常解锁。完成新录入前使用 Windows 密码登录。

必须分别验证正常室内光、暗光、亮光、逆光，并记录检测失败、PAD 拒绝、身份距离/ratio 拒绝和完整耗时；同一批图不能同时充当注册和测试。跨日测试后再判断环境鲁棒性。

渐进式学习需要下一阶段标定：SFace 质量指标与范数、距离门、姿态选槽，以及更新前后异人分布和旧环境保持能力。当前不开启学习，不承诺学习后的收益。

原生数值核对：14 张对齐 chip 全部输出 128 维；与 Python ONNX Runtime 的最大元素误差为 2.91×10⁻⁷，与 OpenCV FaceRecognizerSF 官方接口为 4.47×10⁻⁷，输出范数为 0.99999994–1.00000024。旧 512 维 R50 模型初始化被拒绝。对应聚合记录在已忽略的 `native_sface_validation.json`；单次 14 张推理中位耗时约 4.68 ms，仅为开发机适配检查，不是完整解锁性能基线。

服务、注册 app、Credential Provider 构建通过。CredentialStoreTest、AuthWorkerProtocolTest、ModelIntegrityTest、LivenessTimingTest、TemplateLearnerTest、AuthWorkerLifecycleTest（100 次）通过；凭据测试包含有账户/密码的 V4/V5 停用、读取不改写原文件、V6 模型标识、128 维限制及旧配置学习开关强制关闭。

`scripts/build_installer.ps1` 完整链路通过，包括 `npm run build`（vue-tsc + Vite）、`go test ./...`、声明生成与载荷检查。载荷仅含四个当前模型，旧 R50 已清理，SFace 哈希及包内声明与准备文件一致。安装包为 `installer/FaceLoginSetup/build/bin/FaceLoginSetup.exe`，68028928 字节，SHA-256 `b7245f2434dc82c36f56313cd819ab6800c4eff861a5a01373ff45da7395adf5`。本次切换前的代码检查点为 `70b7403`。

真实摄像头、注册 GUI、Session 0 和锁屏验证需用户在实际机器上操作；本轮未自动安装或修改系统服务。
